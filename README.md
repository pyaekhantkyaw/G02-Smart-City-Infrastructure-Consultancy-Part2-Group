## 📖 Project Overview
UrbanSync Infrastructure Consultancy is a recruitment platform that bridges the gap between specialized talent and smart city initiatives.  

## Key Features
* **Homepage:** Features an interactive hero section with a dynamic slideshow and a direct **Apply Now** call-to-action.
* **Dynamic Job Board:** Fetches live job listings from a MySQL database, complete with a functional search bar for quick filtering.
* **Secure Application Portal:** Powered by PHP with full MySQL integration, featuring server-side validation, CSRF protection, and duplicate submission prevention.
* **HR Management Dashboard:** Includes secure admin authentication, session management, and full CRUD operations to review and manage applications.
* **Explore Page:** Organizes company services, employee benefits, and industry insights into a clean, responsive grid layout.
* **About Page:** Dynamically loads team member contributions from MySQL alongside a group photo and direct LinkedIn profile links.
* **Collaboration Footer:** Provides quick access to Jira boards, the GitHub repository, and direct email contact links.
